API Reference

Abstract type

ForcedInterfacialWaves.AbstractWaveParams — Type
AbstractWaveParams

Abstract supertype for all wave-problem parameter sets.

Subtypes: CapillaryGravityParams, PureGravityParams.

Primary workflow: solve

The public entry point for both regimes. Construct a problem, then call solve:

ForcedInterfacialWaves.ForcedGravityProblem — Type
ForcedGravityProblem(params, x, t)
ForcedGravityProblem(params, x)  # steady-only problem
ForcedGravityProblem(; params, x, t=nothing)

Define a forced pure-gravity interfacial wave problem. The time t is required for method=IVP() and may be omitted for method=steady(rayleigh_dissipation=false).

  • params::PureGravityParams — physical parameters (from compute_gravity_parameters)
  • x — spatial point (Real) or spatial grid (AbstractVector{<:Real})
  • t::Real — nondimensional time for an IVP; nothing for a steady-only problem

Example

pg = compute_gravity_parameters()
prob_ivp = ForcedGravityProblem(pg, -2.0, 1.0 / pg.t_c)
prob_steady = ForcedGravityProblem(pg, make_gravity_xgrid(pg))
sol = solve(prob_steady; method=steady(rayleigh_dissipation=false))
ForcedInterfacialWaves.ForcedGCProblem — Type
ForcedGCProblem(params, x, t)
ForcedGCProblem(params, x)  # steady-only problem
ForcedGCProblem(; params, x, t=nothing)

Define a forced capillary–gravity interfacial wave problem. The time t is required for method=IVP() and may be omitted for method=steady(rayleigh_dissipation=false).

  • params::CapillaryGravityParams — physical parameters (from compute_cg_parameters)
  • x — spatial point (Real) or spatial grid (AbstractVector{<:Real})
  • t::Real — nondimensional time for an IVP; nothing for a steady-only problem

Example

p = compute_cg_parameters()
prob_ivp = ForcedGCProblem(p, 3.0, 110.0)
prob_steady = ForcedGCProblem(p, make_cg_xgrid(p))
sol = solve(prob_steady; method=steady(rayleigh_dissipation=false))

ForcedInterfacialWaves.WaveSolution — Type
WaveSolution

Result returned by solve. Fields:

  • η — total surface displacement (scalar or vector)
  • η_steady — nominal time-independent component used in the IVP decomposition (the symmetric Fourier/PV term for capillary–gravity, equation (4.5b))
  • η_s_local — localized part of the steady component
  • η_s_farfield — far-field wave part of the steady component
  • η_transient — IVP remainder η - η_steady
  • x — spatial coordinate(s) used
  • t — time used (nothing for a time-independent steady solve)

IVP decomposition options

ForcedInterfacialWaves.IVP — Type
IVP(; asym_cancel=false) → IVP

Marker method for the full time-dependent initial-value problem. For a capillary–gravity problem, asym_cancel=false returns the documented equation (4.5b) symmetric steady/transient decomposition. Setting asym_cancel=true uses the asymmetric classical radiation steady reference, so the returned transient is the remainder relative to that reference. The option has no effect on the pure-gravity IVP dispatch.

ForcedInterfacialWaves.steady — Function
steady(; rayleigh_dissipation=false) → SteadyMethod

Construct a steady-state solve method. Enabling Rayleigh dissipation selects the radiation-based asymmetric steady response; disabling it returns the symmetric Fourier steady response.

For capillary–gravity problems, IVP() and IVP(asym_cancel=false) return the symmetric decomposition from equations (4.5a–d). Use IVP(asym_cancel=true) when the transient is referenced to the asymmetric classical radiation profile produced by the long-time cancellation.

Parameters

CapillaryGravityParams and PureGravityParams are mutable. Every physical field is accessible under both an ASCII and a Unicode name (p.alpha ≡ p.α, p.k_l ≡ p.kₗ, etc.), including for destructuring ((; α, β, kₗ, kₛ) = p).

Mutation does not recompute dependent fields

Setting a field in place (e.g. p.alpha = 0.2) does not re-derive quantities that depend on it (k_l, k_s, F0, ...). For any physically consistent change, construct a fresh parameter set with compute_cg_parameters/compute_gravity_parameters keywords instead of mutating an existing instance.

ForcedInterfacialWaves.CapillaryGravityParams — Type
CapillaryGravityParams <: AbstractWaveParams

All nondimensional parameters needed for the capillary-gravity (α > 0) IVP.

Fields are accessible via both ASCII and unicode names: p.alpha ≡ p.α, p.beta ≡ p.β, p.k_l ≡ p.kₗ, p.F0 ≡ p.F₀, etc.

Typing hints (Julia REPL / VS Code): α → \alpha<TAB>, β → \beta<TAB>, ρ → \rho<TAB>, γ → \gamma<TAB>, ε → \varepsilon<TAB>, ₀ → _0<TAB>, ₛ → _s<TAB>, ₗ → _l<TAB>

Fields are accessible via both ASCII and unicode names: p.beta ≡ p.β, p.sqrt_beta ≡ p.sqrtβ, p.F0 ≡ p.F₀, etc.

Pure gravity: unified T₀–T₄ terms

Branch automatically on the side of the wavefront (x vs. t); no separate left/right calls are needed.

ForcedInterfacialWaves.T₀ — Function
T₀(x, p)

Time-independent (steady) contribution. Symmetric in x:

\[T_0(x) = \frac{1}{\pi(1+\rho_r)}\left[-\pi\sin(\beta|x|) + \int_0^\infty \frac{y\,e^{-|x|y}}{\beta^2+y^2}\,dy\right]\]

ForcedInterfacialWaves.T₁ — Function
T₁(x, t, p)

Closed-form transient term. Sign determined by position relative to wavefront:

\[T_1(x,t) = \mp\frac{\sin(\beta x)}{1+\rho_r}\]

Upper sign (−) for x < t, lower sign (+) for x > t.

ForcedInterfacialWaves.T₂ — Function
T₂(x, t, p)

Exponentially-damped oscillatory integral. Valid for any x ≠ t:

\[T_2 = -\frac{4}{\pi(1+\rho_r)\beta}\int_0^{K_{\max}} v^2\, \frac{\exp(\mp 2v^2 a \pm vt\sqrt\beta)}{\beta + (2v-\sqrt\beta)^2} \left[\sqrt\beta\cos(vt\sqrt\beta) \pm (2v-\sqrt\beta)\sin(vt\sqrt\beta)\right]dv\]

ForcedInterfacialWaves.T₃ — Function
T₃(x, t, p)

Fresnel-integral contribution. No quadrature — uses fresnel_C, fresnel_S:

\[T_3 = \frac{\beta^{-1/2}}{\pi(1+\rho_r)}\left(1+\frac{t}{2a}\right)\sqrt{\frac{\pi}{2|a|}} \left[\cos\!\left(\frac{b^2}{|a|}\right)\left(\frac{1}{2}\mp C(X)\right) + \sin\!\left(\frac{b^2}{|a|}\right)\left(\frac{1}{2}\mp S(X)\right)\right]\]

where $a = t-x$, $b = t\sqrt\beta/2$, $X = b\sqrt{2/(\pi|a|)}$.

ForcedInterfacialWaves.T₄ — Function
T₄(x, t, p)

Oscillatory integral. Same formula for both regions — sign enters through $a = t-x$:

\[T_4 = -\frac{1}{\pi(1+\rho_r)}\int_0^{K_{\max}} \frac{\cos(av^2 + vt\sqrt\beta)}{v + \sqrt\beta}\,dv\]

Fresnel integrals

ForcedInterfacialWaves.fresnel_C — Function
fresnel_C(x)

Fresnel cosine integral (matches MATLAB's fresnelc):

\[C(x) = \int_0^x \cos\!\left(\frac{\pi t^2}{2}\right)dt\]

Wraps FresnelIntegrals.fresnelc — O(1) cost, no quadrature.

ForcedInterfacialWaves.fresnel_S — Function
fresnel_S(x)

Fresnel sine integral (matches MATLAB's fresnels):

\[S(x) = \int_0^x \sin\!\left(\frac{\pi t^2}{2}\right)dt\]

Wraps FresnelIntegrals.fresnels — O(1) cost, no quadrature.

Numerical CPV (independent cross-check)

ForcedInterfacialWaves.gravity_combined_integrand — Function
gravity_combined_integrand(k, x, t, p)

Three-term integrand $G(k; x, t)$ for direct numerical CPV evaluation. Terms 1 and 2 are individually singular at $k = \beta$; they cancel when combined:

\[G = \frac{\cos(kx)}{\pi(1+\rho_r)(k-\beta)} - \frac{k\cos[k(t-x)-t\sqrt{\beta k}]}{2\pi(1-\rho_r)(k-\sqrt{\beta k})} - \frac{k\cos[k(t-x)+t\sqrt{\beta k}]}{2\pi(1-\rho_r)(k+\sqrt{\beta k})}\]

ForcedInterfacialWaves.gravity_numerical_cpv — Function
gravity_numerical_cpv(x, t, p)

Direct numerical Cauchy principal value evaluation, split symmetrically around $k = \beta$:

\[\eta_{\mathrm{CPV}}(x,t) = F_0\left[ \int_0^{\beta-\varepsilon} G(k;x,t)\,dk + \int_{\beta+\varepsilon}^{K_{\max}} G(k;x,t)\,dk \right]\]

where $G$ is gravity_combined_integrand. Uses order=15 for the oscillatory interval above the pole.

Capillary–gravity: dispersion and integrands

ForcedInterfacialWaves.dispersion_chi — Function
dispersion_chi(k, p) → χ(k)

Two-fluid capillary–gravity dispersion function:

\[\chi(k) = \sqrt{\beta k + \gamma_\rho \alpha k^3}\]

ForcedInterfacialWaves.cg_integrand_steady — Function
cg_integrand_steady(k, x, p)

The $\eta_s$ integrand (eq. 2.22 of supplementary):

\[\frac{2\cos(kx)}{\alpha(k - k_l)(k - k_s)}\]

ForcedInterfacialWaves.cg_integrand_I3 — Function
cg_integrand_I3(k, x, t, p)

The $\mathbb{I}_3$ integrand (eq. 2.40 of supplementary):

\[-\frac{(1+\rho_r)(k+\chi)}{1+\alpha k^2-\rho_r}\cdot \frac{\cos[k(t-x)-t\chi]}{\alpha(k-k_l)(k-k_s)}\]

ForcedInterfacialWaves.cg_integrand_I4 — Function
cg_integrand_I4(k, x, t, p)

The $\mathbb{I}_4$ integrand (eq. 2.41 of supplementary):

\[-\frac{(1+\rho_r)(k-\chi)}{1+\alpha k^2-\rho_r}\cdot \frac{\cos[k(t-x)+t\chi]}{\alpha(k-k_l)(k-k_s)}\]

ForcedInterfacialWaves.cg_combined_integrand — Function
cg_combined_integrand(k, x, t, p)

Combined integrand $\mathbb{I}(k; x, t)$ with singularities cancelling in the sum:

\[\mathbb{I} = \frac{2\cos(kx)}{\alpha(k-k_l)(k-k_s)} - \frac{(1+\rho_r)(k+\chi)}{1+\alpha k^2 - \rho_r}\, \frac{\cos[k(t-x)-t\chi]}{\alpha(k-k_l)(k-k_s)} - \frac{(1+\rho_r)(k-\chi)}{1+\alpha k^2 - \rho_r}\, \frac{\cos[k(t-x)+t\chi]}{\alpha(k-k_l)(k-k_s)}\]

Uses @fastmath; computes $\chi(k)$ once and shares common subexpressions.

ForcedInterfacialWaves.cg_I3 — Function
cg_I3(x, t, p; epsilon_pv=p.epsilon_pv, atol=p.atol,
      rtol=p.rtol, k_max=p.k_max) → value

Evaluate the standalone $\mathbb{I}_3(x,t)$ integral from equation (4.5d). Because the separate $\mathbb{I}_3$ integrand has poles at $k_s$ and $k_l$, this function uses the package's pole-exclusion/CPV convention over three intervals. The result is a diagnostic component; the production IVP integrates the combined steady + $\mathbb{I}_3$ + $\mathbb{I}_4$ integrand.

ForcedInterfacialWaves.cg_I4 — Function
cg_I4(x, t, p; atol=p.atol, rtol=p.rtol, k_max=p.k_max) → value

Evaluate the standalone $\mathbb{I}_4(x,t)$ integral from equation (4.5d). The apparent poles are removed algebraically before quadrature, so this integral is evaluated directly over $[0, k_max]$ without pole splitting.

𝕀₃ and 𝕀₄ are Unicode aliases for cg_I3 and cg_I4. cg_I3 uses the standalone pole-split CPV convention; cg_I4 uses the algebraically regularized non-singular integrand. These component functions are diagnostic APIs; the production solve path integrates the combined integrand.

Quadrature and profiles

ForcedInterfacialWaves.cg_partial_integrals — Function
cg_partial_integrals(x, t, p) → (I1, I2, I3)

Returns the three partial integrals of the combined integrand $\mathbb{I}$ (eq. 2.17 of supplementary), split around the removable poles at $k_s$ and $k_l$:

\[I_1 = \int_0^{k_s-\varepsilon} \mathbb{I}\,dk, \quad I_2 = \int_{k_s+\varepsilon}^{k_l-\varepsilon} \mathbb{I}\,dk, \quad I_3 = \int_{k_l+\varepsilon}^{k_{\max}} \mathbb{I}\,dk\]

These can be validated individually against MATLAB's integral_1, integral_2, integral_3.

For performance-critical profiles, use compute_cg_ivp_profile which evaluates all spatial points simultaneously via in-place vector-valued quadrature.

ForcedInterfacialWaves.ivp_surface_elevation — Function
ivp_surface_elevation(x, t, p)

Evaluate $\eta(x,t)$ at a single spatial point (eq. 2.17 of supplementary):

\[\eta(x,t) = -\frac{F_0}{2\pi}\left(I_1 + I_2 + I_3\right)\]

where $I_1, I_2, I_3$ are the partial integrals over [0, k_s−ε], [k_s+ε, k_l−ε], [k_l+ε, ∞).

ForcedInterfacialWaves.cg_Gx_integral — Function
cg_Gx_integral(x, p) → G(x)

Auxiliary integral for the steady solution:

\[G(x) = \frac{1}{k_l - k_s}\int_0^{k_{\max}} \left[\frac{\cos(kx)}{k+k_s} - \frac{\cos(kx)}{k+k_l}\right]dk\]

Exposed for independent validation against MATLAB.

ForcedInterfacialWaves.steady_surface_elevation — Function
steady_surface_elevation(x, p; rayleigh_dissipation=true)

Classical steady capillary–gravity solution obtained via residue calculus. The default rayleigh_dissipation=true returns the asymmetric radiation profile used for long-time comparisons. Set rayleigh_dissipation=false for the symmetric nominal steady term in equation (4.5b), which is the component used by the CG IVP WaveSolution.

\[\frac{\eta_{\text{steady}}(x)}{F_0} = \begin{cases} -\dfrac{2}{\alpha(k_l-k_s)}\sin(k_s x) + \dfrac{G(x)}{\pi\alpha}, & x > 0 \\[6pt] -\dfrac{2}{\alpha(k_l-k_s)}\sin(k_l x) + \dfrac{G(x)}{\pi\alpha}, & x < 0 \end{cases}\]

where $G(x)$ is computed by cg_Gx_integral.

ForcedInterfacialWaves.compute_cg_ivp_profile — Function
compute_cg_ivp_profile(x_grid, t, p; method=:threaded_vector,
                       atol=p.atol, rtol=p.rtol)

Available algorithms:

  • :threaded_vector (production default): one in-place vector quadrature per thread-local spatial chunk; shares adaptation and uses all Julia threads.
  • :vector: one in-place vector quadrature for the complete profile.
  • :threaded_scalar: independent per-x quadrature retained as the reference.
ForcedInterfacialWaves.compute_cg_I3_profile — Function
compute_cg_I3_profile(x_grid, t, p; method=:threaded_vector, ...)

Compute the standalone $\mathbb{I}_3$ profile using the pole-split CPV convention. The threaded-vector method is the production default.

ForcedInterfacialWaves.compute_cg_I4_profile — Function
compute_cg_I4_profile(x_grid, t, p; method=:threaded_vector, ...)

Compute the standalone regularized $\mathbb{I}_4$ profile directly over $[0, k_max]$. The threaded-vector method shares each quadrature node's $\chi$ and time phase across the spatial chunk.

ForcedInterfacialWaves.compute_cg_steady_profile — Function
compute_cg_steady_profile(x_grid, p; rayleigh_dissipation=true,
                           atol=p.atol, rtol=p.rtol)

Compute the capillary–gravity steady profile. With the default rayleigh_dissipation=true, return the asymmetric classical radiation profile used for long-time comparisons. With false, return the symmetric nominal Fourier/PV steady term from equation (4.5b), which is the steady component of the CG IVP decomposition.

ForcedInterfacialWaves.compute_cg_profile — Function
compute_cg_profile(x_grid, t, p; method=:threaded_vector,
                   compute_steady=true, rayleigh_dissipation=false,
                   atol=p.atol, rtol=p.rtol)

Compatibility wrapper returning (eta_ivp, eta_steady). By default the second return value is the symmetric nominal steady term from equation (4.5b), so the identity eta_ivp == eta_steady + eta_transient matches the documented CG IVP decomposition. Set rayleigh_dissipation=true to request the asymmetric classical steady profile instead. Set compute_steady=false to skip that calculation and return nothing as the second value.

ForcedInterfacialWaves.make_cg_xgrid — Function
make_cg_xgrid(p; Nx=2001, xlim=nothing)

Nondimensional spatial grid, excluding x ≈ 0. By default the grid spans [-p.L/(2p.l_c), p.L/(2p.l_c)]. Set xlim=(xmin, xmax) to use a restricted nondimensional domain instead.

Unicode utilities

ForcedInterfacialWaves.∫ — Function
∫(f, a, b; kw...) → value

Unicode alias for numerical integration. Returns the integral value only (discards the error estimate). Wraps QuadGK.quadgk.

Example

using ForcedInterfacialWaves: ∫
result = ∫(sin, 0, π)   # ≈ 2.0

Backward compatibility

Older, pre-solve low-level pure-gravity entry points (gravity_T0, gravity_T1_left/gravity_T1_right through gravity_T4_left/gravity_T4_right, gravity_analytical_left, gravity_analytical_right) remain in the package as thin, undocumented wrappers around T₀–T₄ for compatibility with earlier scripts. dispersion_omega is likewise kept as an undocumented const alias of dispersion_chi. None of these are part of the recommended API surface — new code should use solve(ForcedGravityProblem(...)), the unified T₀–T₄ functions, and dispersion_chi directly.
