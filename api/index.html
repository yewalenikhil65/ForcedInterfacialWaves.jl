Fresnel integrals

ForcedInterfacialWaves.fresnel_C — Function
fresnel_C(x)

Fresnel cosine integral (matches MATLAB's fresnelc):

\[C(x) = \int_0^x \cos\!\left(\frac{\pi t^2}{2}\right)dt\]

Wraps FresnelIntegrals.fresnelc — O(1) cost, no quadrature.

ForcedInterfacialWaves.fresnel_S — Function
fresnel_S(x)

Fresnel sine integral (matches MATLAB's fresnels):

\[S(x) = \int_0^x \sin\!\left(\frac{\pi t^2}{2}\right)dt\]

Wraps FresnelIntegrals.fresnels — O(1) cost, no quadrature.

Analytical terms

ForcedInterfacialWaves.gravity_T0 — Function
gravity_T0(x, p)

Time-independent (steady) contribution:

\[T_0(x) = \frac{1}{\pi(1+\rho_r)}\left[-\pi\sin(\beta|x|) + \int_0^\infty e^{-y|x|}\frac{y}{\beta^2+y^2}\,dy\right]\]

ForcedInterfacialWaves.gravity_T1_left — Function
gravity_T1_left(x, p)

First transient contribution (left region, closed-form):

\[T_1^-(x) = -\frac{\sin(\beta x)}{1+\rho_r}\]

ForcedInterfacialWaves.gravity_T2_left — Function
gravity_T2_left(x, t, a, p)

Exponentially-damped oscillatory integral (left region, $a = t-x > 0$):

\[T_2^- = -\frac{4}{\pi(1+\rho_r)\beta}\int_0^{K_{\max}} v^2\, e^{-2v^2 a + vt\sqrt\beta}\, \frac{\sqrt\beta\cos(vt\sqrt\beta) + (2v-\sqrt\beta)\sin(vt\sqrt\beta)} {\beta + (2v-\sqrt\beta)^2}\,dv\]

ForcedInterfacialWaves.gravity_T3_left — Function
gravity_T3_left(x, t, a, p)

Fresnel-integral contribution (left region). No quadrature — uses fresnel_C, fresnel_S:

\[T_3^- = \frac{1}{\pi(1+\rho_r)\sqrt\beta} \left(1+\frac{t}{2a}\right)\sqrt{\frac{\pi}{2a}}\, \left[\cos\!\left(\frac{b^2}{a}\right)\!\left(\tfrac12 - C(X)\right) + \sin\!\left(\frac{b^2}{a}\right)\!\left(\tfrac12 - S(X)\right)\right]\]

where $b = t\sqrt\beta/2$, $X = b\sqrt{2/(\pi a)}$.

ForcedInterfacialWaves.gravity_T4_left — Function
gravity_T4_left(x, t, a, p)

Oscillatory integral (left region):

\[T_4^- = -\frac{1}{\pi(1+\rho_r)}\int_0^{K_{\max}} \frac{\cos(v^2 a + vt\sqrt\beta)}{v + \sqrt\beta}\,dv\]

ForcedInterfacialWaves.gravity_T1_right — Function
gravity_T1_right(x, p)

First transient contribution (right region, closed-form):

\[T_1^+(x) = +\frac{\sin(\beta x)}{1+\rho_r}\]

ForcedInterfacialWaves.gravity_T2_right — Function
gravity_T2_right(x, t, a, p)

Exponentially-damped oscillatory integral (right region, $a = t-x < 0$):

\[T_2^+ = -\frac{4}{\pi(1+\rho_r)\beta}\int_0^{K_{\max}} v^2\, e^{2v^2 a - vt\sqrt\beta}\, \frac{\sqrt\beta\cos(vt\sqrt\beta) - (2v-\sqrt\beta)\sin(vt\sqrt\beta)} {\beta + (2v-\sqrt\beta)^2}\,dv\]

Note: $a < 0$ so $\exp(2v^2 a)$ decays.

ForcedInterfacialWaves.gravity_T3_right — Function
gravity_T3_right(x, t, a, p)

Fresnel-integral contribution (right region, $a < 0$). Uses $|a|$ and flipped signs:

\[T_3^+ = \frac{1}{\pi(1+\rho_r)\sqrt\beta} \left(1+\frac{t}{2a}\right)\sqrt{\frac{\pi}{2|a|}}\, \left[\cos\!\left(\frac{b^2}{|a|}\right)\!\left(\tfrac12 + C(X)\right) + \sin\!\left(\frac{b^2}{|a|}\right)\!\left(\tfrac12 + S(X)\right)\right]\]

where $b = t\sqrt\beta/2$, $X = b\sqrt{2/(\pi|a|)}$.

ForcedInterfacialWaves.gravity_T4_right — Function
gravity_T4_right(x, t, a, p)

Oscillatory integral (right region). Same formula as $T_4^-$; sign enters through $a < 0$:

\[T_4^+ = -\frac{1}{\pi(1+\rho_r)}\int_0^{K_{\max}} \frac{\cos(v^2 a + vt\sqrt\beta)}{v + \sqrt\beta}\,dv\]

ForcedInterfacialWaves.gravity_analytical_left — Function
gravity_analytical_left(x, t, p) → (η_total, η_steady, η_transient)

Complete analytical solution for $x < t - \delta_x$ (behind the wavefront):

\[\eta^-(x,t) = F_0\left[T_0(x) + T_1^- + T_2^- + T_3^- + T_4^-\right]\]

Returns a tuple (η_total, η_steady, η_transient) where η_steady = F₀ T₀ and η_transient = F₀(T₁⁻ + T₂⁻ + T₃⁻ + T₄⁻).

ForcedInterfacialWaves.gravity_analytical_right — Function
gravity_analytical_right(x, t, p) → (η_total, η_steady, η_transient)

Complete analytical solution for $x > t + \delta_x$ (ahead of wavefront):

\[\eta^+(x,t) = F_0\left[T_0(x) + T_1^+ + T_2^+ + T_3^+ + T_4^+\right]\]

Numerical CPV

ForcedInterfacialWaves.gravity_combined_integrand — Function
gravity_combined_integrand(k, x, t, p)

Three-term integrand $G(k; x, t)$ for direct numerical CPV evaluation. Terms 1 and 2 are individually singular at $k = \beta$; they cancel when combined:

\[G = \frac{\cos(kx)}{\pi(1+\rho_r)(k-\beta)} - \frac{k\cos[k(t-x)-t\sqrt{\beta k}]}{2\pi(1-\rho_r)(k-\sqrt{\beta k})} - \frac{k\cos[k(t-x)+t\sqrt{\beta k}]}{2\pi(1-\rho_r)(k+\sqrt{\beta k})}\]

ForcedInterfacialWaves.gravity_numerical_cpv — Function
gravity_numerical_cpv(x, t, p)

Direct numerical Cauchy principal value evaluation, split symmetrically around $k = \beta$:

\[\eta_{\mathrm{CPV}}(x,t) = F_0\left[ \int_0^{\beta-\varepsilon} G(k;x,t)\,dk + \int_{\beta+\varepsilon}^{K_{\max}} G(k;x,t)\,dk \right]\]

where $G$ is gravity_combined_integrand. Uses order=15 for the oscillatory interval above the pole.

Dispersion and integrands

ForcedInterfacialWaves.dispersion_chi — Function
dispersion_chi(k, p) → χ(k)

Two-fluid capillary–gravity dispersion function:

\[\chi(k) = \sqrt{\beta k + \gamma_\rho \alpha k^3}\]

ForcedInterfacialWaves.cg_integrand_steady — Function
cg_integrand_steady(k, x, p)

The $\eta_s$ integrand (eq. 2.22 of supplementary):

\[\frac{2\cos(kx)}{\alpha(k - k_l)(k - k_s)}\]

ForcedInterfacialWaves.cg_integrand_I3 — Function
cg_integrand_I3(k, x, t, p)

The $\mathbb{I}_3$ integrand (eq. 2.40 of supplementary):

\[-\frac{(1+\rho_r)(k+\chi)}{1+\alpha k^2-\rho_r}\cdot \frac{\cos[k(t-x)-t\chi]}{\alpha(k-k_l)(k-k_s)}\]

ForcedInterfacialWaves.cg_integrand_I4 — Function
cg_integrand_I4(k, x, t, p)

The $\mathbb{I}_4$ integrand (eq. 2.41 of supplementary):

\[-\frac{(1+\rho_r)(k-\chi)}{1+\alpha k^2-\rho_r}\cdot \frac{\cos[k(t-x)+t\chi]}{\alpha(k-k_l)(k-k_s)}\]

ForcedInterfacialWaves.cg_combined_integrand — Function
cg_combined_integrand(k, x, t, p)

Combined integrand $\mathbb{I}(k; x, t)$ with singularities cancelling in the sum:

\[\mathbb{I} = \frac{2\cos(kx)}{\alpha(k-k_l)(k-k_s)} - \frac{(1+\rho_r)(k+\chi)}{1+\alpha k^2 - \rho_r}\, \frac{\cos[k(t-x)-t\chi]}{\alpha(k-k_l)(k-k_s)} - \frac{(1+\rho_r)(k-\chi)}{1+\alpha k^2 - \rho_r}\, \frac{\cos[k(t-x)+t\chi]}{\alpha(k-k_l)(k-k_s)}\]

Uses @fastmath; computes $\chi(k)$ once and shares common subexpressions.

Quadrature and profiles

ForcedInterfacialWaves.cg_partial_integrals — Function
cg_partial_integrals(x, t, p) → (I1, I2, I3)

Returns the three partial integrals of the combined integrand $\mathbb{I}$ (eq. 2.17 of supplementary), split around the removable poles at $k_s$ and $k_l$:

\[I_1 = \int_0^{k_s-\varepsilon} \mathbb{I}\,dk, \quad I_2 = \int_{k_s+\varepsilon}^{k_l-\varepsilon} \mathbb{I}\,dk, \quad I_3 = \int_{k_l+\varepsilon}^{k_{\max}} \mathbb{I}\,dk\]

These can be validated individually against MATLAB's integral_1, integral_2, integral_3.

For performance-critical profiles, use compute_cg_ivp_profile which evaluates all spatial points simultaneously via in-place vector-valued quadrature.

ForcedInterfacialWaves.ivp_surface_elevation — Function
ivp_surface_elevation(x, t, p)

Evaluate $\eta(x,t)$ at a single spatial point (eq. 2.17 of supplementary):

\[\eta(x,t) = -\frac{F_0}{2\pi}\left(I_1 + I_2 + I_3\right)\]

where $I_1, I_2, I_3$ are the partial integrals over [0, k_s−ε], [k_s+ε, k_l−ε], [k_l+ε, ∞).

ForcedInterfacialWaves.cg_Gx_integral — Function
cg_Gx_integral(x, p) → G(x)

Auxiliary integral for the steady solution:

\[G(x) = \frac{1}{k_l - k_s}\int_0^{k_{\max}} \left[\frac{\cos(kx)}{k+k_s} - \frac{\cos(kx)}{k+k_l}\right]dk\]

Exposed for independent validation against MATLAB.

ForcedInterfacialWaves.steady_surface_elevation — Function
steady_surface_elevation(x, p)

Classical steady capillary–gravity solution (obtained via residue calculus):

\[\frac{\eta_{\text{steady}}(x)}{F_0} = \begin{cases} -\dfrac{2}{\alpha(k_l-k_s)}\sin(k_s x) + \dfrac{G(x)}{\pi\alpha}, & x > 0 \\[6pt] -\dfrac{2}{\alpha(k_l-k_s)}\sin(k_l x) + \dfrac{G(x)}{\pi\alpha}, & x < 0 \end{cases}\]

where $G(x)$ is computed by cg_Gx_integral.

ForcedInterfacialWaves.compute_cg_ivp_profile — Function
compute_cg_ivp_profile(x_grid, t, p; method=:threaded_vector,
                       atol=p.atol, rtol=p.rtol)

Available algorithms:

  • :threaded_vector (production default): one in-place vector quadrature per thread-local spatial chunk; shares adaptation and uses all Julia threads.
  • :vector: one in-place vector quadrature for the complete profile.
  • :threaded_scalar: independent per-x quadrature retained as the reference.
